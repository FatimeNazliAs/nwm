Navigation World Models

A robot that plans by imagining: instead of mapping an image straight to an action, it generates the future it would see for a set of actions, then picks the actions whose imagined future best reaches the goal.

Bar, Zhou, Tran, Darrell, LeCun — FAIR at Meta & NYU · arXiv:2412.03572

In one line: NWM is a controllable video-generation model — give it the current view and a navigation action, and it predicts the next view. Chain those predictions and you can simulate whole trajectories and plan on top of them.

The shift it makes

Usual navigation policy

image → policy → action

Reactive. Behaviour is baked in at training time — you can't later say "no left turns," and it can't reason far ahead. (GNM, ViNT, NoMaD work this way.)

Navigation World Model

image + actions → future images

Predicts the world, not the action. Planning then happens inside the model — sample actions, imagine outcomes, keep the best. Constraints can be added at plan time, no retraining.

Input & output

Input

  • Observations — the current view plus up to 4 past frames (context).
  • Action — where to move and turn: translation u ∈ ℝ² (forward/back, left/right) and yaw φ.
  • Time-shift k — how far ahead to jump, up to ±16 s. This is what makes "predict N seconds later" a single call.

Output

  • A predicted observation — the frame the agent would see after that action.
  • Feed it back in and the model produces the next one, and the next — an imagined video.
  • Stochastic — sampling different noise gives different plausible futures, so a plan can be scored over several rolls.

Under the hood

CDiT

Conditional Diffusion Transformer

The world model itself, ~1B params. Denoises the next frame while attending to context frames by cross-attention. Cost grows linearly with context — ≈4× fewer FLOPs than a plain DiT.

VAE frozen

Stable Diffusion sd-vae-ft-ema

An off-the-shelf autoencoder that compresses each image to a small latent and back. NWM does not train it — it just borrows it so the transformer works on compact latents.

Conditioning

action + time + timestep → AdaLN

The action, the time-shift, and the diffusion timestep each become an embedding; they're summed into one vector ξ that modulates every block via AdaLN.

What it can do

Covered in our teardown In the paper, beyond our teardown

Predict (one-shot / "time")

In scope

Given a start frame + action, predict the frame N seconds ahead in a single forward pass. This is the slice our teardown follows, end to end, on RECON.

Rollout

Deferred

Feed each prediction back in to autoregressively imagine a full video — up to 16 s of navigation from a single first image and an action sequence.

Standalone planning

Deferred

Use NWM as a dynamics model in MPC: sample action sequences (Cross-Entropy Method), simulate each, and keep the one whose final frame looks most like the goal.

Ranking an external policy

Deferred

Let NoMaD propose 16–32 trajectories, simulate them all with NWM, and rank by goal similarity. Improves navigation over the policy alone.

Planning with constraints

Deferred

Forbid or force moves at plan time ("forward first," "no left") by zeroing those actions — behaviour changes with no retraining.

Imagination in unknown places

Deferred

From a single image in an unseen environment, hallucinate plausible trajectories using visual priors — sharpened by unlabeled Ego4D training.

Trained & measured on

Datasets

RECONSCAND TartanDriveHuRoN Ego4D · unlabeled Go Stanford · OOD test

Robot datasets give real actions (pose + yaw); Ego4D adds action-free video where only time-shift is known. Go Stanford is held out to test unseen environments.

Metrics

LPIPSDreamSimPSNR FIDFVD ATERPE

Perceptual similarity to ground truth (LPIPS, DreamSim, PSNR), generation quality (FID, FVD), and trajectory accuracy for the planning experiments (ATE, RPE).
